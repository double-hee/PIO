메뉴에 ‘앱 설치’가 안 보여요

이미 설치되어 있거나, 카카오톡·밴드 안의 임시 브라우저로 열린 경우입니다. 먼저 홈 화면에 PIO 아이콘이 있는지 확인하고, 없다면 크롬 앱을 직접 열어 주소를 입력해 보세요.

아이폰인데 ‘홈 화면에 추가’가 없어요

사파리가 아닌 브라우저로 열었기 때문입니다. 아이폰은 Safari에서만 홈 화면 추가가 됩니다. 사파리를 직접 열고 주소를 입력해 주세요.

설치했는데 화면이 예전 그대로예요

이전 화면이 저장되어 있는 경우입니다. 아이콘을 길게 눌러 삭제한 뒤 다시 설치하면 최신 화면으로 열립니다.

이름 목록에 제 이름이 없어요

참여 인원 명단에 아직 등록되지 않은 경우입니다. 이중희에게 알려 주시면 명단에 추가해 드립니다.

설치가 안 되면 화면을 캡처해서 이중희에게 보내 주세요.
